# AGENTS

basis-swift is the Swift package for [basis](https://github.com/oops-rs/basis). It follows
basis's and [mentra](https://github.com/oops-rs/mentra)'s conventions; when in doubt, basis's
AGENTS.md is the reference.

## Project Rules

- The product is the Swift package `Basis`, for Swift only (ADR-0001). `rust/` is how it is
  built: a UniFFI crate over the published `basis`.
- The binding mirrors basis; it never adds behavior. A gap in what basis exposes is fixed in
  basis, with an issue filed there, not worked around here. basis knows nothing about this
  package: no UniFFI derive or FFI type goes into basis.
- Events cross as the JSONL `EventLine` (`basis spawn --json`'s wire) and Swift wraps the line
  as `Event`; never mirror basis's `Event` enum.
- A Swift seam fails closed: a throwing approver denies, a throwing observer ends the run.
- `Sources/BasisBindings/` is generated by `scripts/build-xcframework.sh` and committed;
  never edit it by hand. Regenerate it in the same commit as the Rust change that alters it.
- Swift 6.4 tools; hand-written Swift (`Sources/Basis/`) and tests are in Swift 6 mode. Only
  `BasisBindings` builds in Swift 5 mode, because UniFFI's generated async callbacks fail
  Swift 6's data-race checks (ADR-0001 §8).
- Decisions go in `docs/adr/` (numbered, Context/Decision/Consequences).

## Building and testing

- `PLATFORMS=macos scripts/build-xcframework.sh` builds the macOS slice for local work;
  without `PLATFORMS` it builds macOS, iOS and the simulator.
- `swift test` runs the package tests. Once `Package.swift` points at a release, set
  `BASIS_SWIFT_LOCAL_FFI=1` to test against the local build instead.
- In `rust/`: `cargo fmt`, and `cargo clippy --all-targets -- -D warnings` must pass.
- Never export `MACOSX_DEPLOYMENT_TARGET` for a cargo build: it reaches the host proc-macro
  dylibs and macOS's loader refuses them. The script sets C floors through `CFLAGS_<target>`.

## Workflow Discipline

- Commit each completed step before starting the next step.

## Commit Style

- Conventional Commits: `<type>(<scope>): <summary>`, types `feat`, `fix`, `docs`, `refactor`,
  `chore`, `test`; narrow scopes; imperative summaries.

## Rust Programming

- Edition 2024, MSRV 1.95. Prefer `foo.rs` plus `foo/` over `foo/mod.rs`.
- `uniffi` stays pinned to an exact version (`=x.y.z`): the committed Swift and the scaffolding
  must match.
