# basis-swift

[basis](https://github.com/oops-rs/basis), the embeddable agent harness, as a Swift package.
The harness runs in your app's process on macOS and iOS: no `basis` binary and no subprocess.
Your approver and your event view are ordinary Swift.

```swift
.package(url: "https://github.com/oops-rs/basis-swift", from: "0.1.0")
```

Swift 6.4 or later; macOS 13, iOS 16.

## Use

```swift
import Basis

let workspace = try await Workspace.open(
    path: repoURL.path,
    options: WorkspaceOptions(provider: .anthropic, apiKey: key, history: .directory(path: historyDir))
)

let run = try workspace.prepare()
let report = try await run.send("what does this repo do?") { event in
    if let text = event.assistantText { print(text, terminator: "") }
}
print(report.outcome, report.usage.totalTokens)

// Same conversation: the model sees everything said so far.
try await run.send("and which part is riskiest?")
```

Every `WorkspaceOptions` field is optional. basis reads no `config.json` unless you name one
with `configFile`.

### Approving tool calls

Without an approver every call is allowed. With one, each consequential call waits for your
answer, and an approver that throws denies:

```swift
try await run.send("bump the deps", approve: { request in
    request.sideEffectLevel == .localState ? .allow : .deny("this app allows local edits only")
})
```

A denial's reason is what the model reads as the call's result, so say what it should do next.
With both closures, the observer is the trailing closure and `approve:` follows it:

```swift
try await run.send("bump the deps") { event in
    print(event.type)
} approve: { request in
    request.sideEffectLevel == .localState ? .allow : .deny("this app allows local edits only")
}
```

### Stopping

```swift
let control = TurnControl()
stopButton.action = { control.stop() }    // end at the next round, keep the work
cancelButton.action = { control.cancel() } // abandon the turn and roll it back
try await run.send(prompt, control: control)
```

### Events

`onEvent` receives every event of the turn, in order, on a basis thread. Hop to your own actor
before touching UI. Each `Event` is one line of basis's
[JSONL stream](https://github.com/oops-rs/basis/blob/main/docs/embedding.md): `type` names it,
and `decode(_:)` reads the fields you need into your own `Decodable`.

### Resuming

`run.agentId()` names the conversation. `workspace.resume(agentId:)` picks it up later, from the
same workspace's history.

## Developing

You need Rust 1.95 or later with the Apple targets
(`rustup target add aarch64-apple-darwin x86_64-apple-darwin aarch64-apple-ios aarch64-apple-ios-sim x86_64-apple-ios`)
and Xcode.

```sh
PLATFORMS=macos scripts/build-xcframework.sh   # Rust → build/BasisFFI.xcframework + generated Swift
swift test
```

`scripts/release.sh <version>` builds every slice and prepares the release. The decisions behind
the package are in [`docs/adr/`](docs/adr/).
